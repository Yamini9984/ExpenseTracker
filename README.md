# 💰 Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript.  
This app allows users to track income and expenses and calculate their balance dynamically.

🌐 Live Demo: https://vercel.com/yamini-projects/expense-tracker

---

## 🚀 Features

- ✅ Add Income
- ✅ Add Expenses
- ✅ Automatic Balance Calculation
- ✅ Displays Total Income
- ✅ Displays Total Expenses
- ✅ Clean and Responsive UI
- ✅ Hosted on Vercel

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Vercel (Deployment)

## 📸 How It Works

1. Enter Description
2. Enter Amount
3. Select Income or Expense
4. Click "Add Expense"
5. Balance updates automatically
